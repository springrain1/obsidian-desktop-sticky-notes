# 别再用系统便签了，Obsidian 里的这张便签纸，才是知识管理该有的样子

---

你有没有过这样的经历——

开着浏览器查资料，脑子里闪过一句话，赶紧 Win+V 调出系统便签，刷刷记两行。开会时又贴一张，看视频时又贴一张……

几天后桌面上趴着十几张便签。**你知道那个想法记过，但死活找不到在哪张上面。**

更要命的是，这些系统便签和你的笔记本、知识库、项目文档之间，隔着一道看不见的墙——它们是孤岛，永远无法被搜索、被链接、被纳入你的知识体系。

今天介绍的这个 Obsidian 插件，就是来拆掉这堵墙的。

---

## 为什么我们离不开便签？

便签之所以历久不衰，是因为它踩中了人脑最本能的需求：

**1. 零摩擦捕获**

灵感的保鲜期大约 7 秒。打开一个 App、新建一个文件、选一个目录——这套流程走完，念头早就溜了。便签的核心价值就是"抬手就写"，它不要你思考"这条应该放在哪个文件夹里"。

**2. 常驻视野**

贴在显示器边上的便签为什么有效？因为它不需要你"想起来去看"，它就**一直在你眼前**。系统便签的置顶功能也是同理——写完钉在那里，切到任何窗口都能瞥一眼。

**3. 轻量无压力**

打开一个正式的笔记文档，你会不自觉地想"我得写得完整一点"。但便签不一样，它的物理形态就在暗示你：**随便写，几个字就够。** 这种心理安全感，让你更愿意把不成熟的碎片想法先落地。

---

## 系统便签的致命短板

Windows 自带的 Sticky Notes、macOS 的备忘录贴纸，能用，但有三个根本性问题：

| 痛点 | 具体表现 |
|:---|:---|
| **数据孤岛** | 便签内容无法被你的知识库搜索到，也不能和其他笔记建立链接 |
| **格式受限** | 不支持 Markdown，没有待办勾选、标题层级、双向链接 |
| **同步割裂** | 系统便签走自己的同步通道，和你的笔记同步方案完全两套 |

本质上，系统便签是一个"写完就忘"的工具。它解决了"快速捕获"，但**完全没考虑"之后怎么办"**。

---

## 把便签种进 Obsidian

**Desktop Sticky Notes**（桌面便笺）做的事情很简单：

> **给你一张拟物化的桌面便签纸，但它的背后是一个标准的 Obsidian Markdown 文件。**

你往便签上写的每一个字，都是 `.md` 文件里的纯文本。它可以被全库搜索到，可以用 `[[双向链接]]` 连接到任何笔记，可以被 Dataview 查询到，可以跟着你的 Git/Syncthing/iCloud 同步到任何地方。

**便签不再是孤岛，它是你知识库的入口。**

---

## 它长什么样？

想象一下 Windows 经典便签的样子——一张有颜色的小纸片，悬浮在桌面上。Desktop Sticky Notes 就是这个手感，但比系统便签多了太多东西：

### 🪟 独立小窗，真·桌面置顶

便签以独立窗口弹出，脱离 Obsidian 主界面。你可以一键置顶，让它悬浮在浏览器、IDE、Office 的上面——写代码时瞟一眼 TODO，开会时随手记一句，不用在窗口间反复切换。

### 🎨 7 款便签纸皮肤

不是简单换个背景色。每款皮肤都调校了底色、边框、顶栏和文字的色彩搭配：

- 🟡 **经典黄**——最正宗的纸质便签感
- 🟢 **薄荷绿**——适合日程与任务规划
- 🌸 **樱花粉**——灵感便签，一眼就认出来
- 🔷 **晴空蓝**——沉稳干练的工作手记
- 🟣 **香芋紫**——读书札记与思考片段
- ⚪ **简约白**——极简纯净
- ⚫ **暗夜碳黑**——深色模式专属，夜间护眼

你可以用颜色来区分便签的用途：黄色给日常杂事，粉色给灵感，蓝色给工作……**一瞥便知。**

### ⚡ 原生 Live Preview 所见即所得

这是它和所有第三方便签应用最大的区别。便签内部直接跑的是 Obsidian 原生的 CodeMirror 6 编辑器引擎：

- 敲 `- [ ] 买牛奶` → 直接显示为可点击的复选框 ☑️
- 敲 `## 今日重点` → 即时渲染为二级标题
- 敲 `[[项目文档]]` → 可以直接链接到你库里的其他笔记
- 支持**加粗**、~~删除线~~、`代码`、==高亮==……一切 Markdown 语法即打即显

这意味着你的便签不只是一张"纯文本纸条"，它是一个**完整的 Obsidian 编辑视图**，只不过穿了一身便签纸的衣服。

### 🛠️ 悬浮富文本工具栏

不记得 Markdown 语法？没关系。顶部工具栏提供了一排快捷按钮：

- **待办清单**：一键插入，支持多行批量打勾/取消
- **无序 & 有序列表**：多行选中一键转换，有序列表自动递增编号
- **删除线**：选中文字一键划掉
- **插入图片**：点击直接弹出文件选择器，图片自动存入 Vault
- **标题 / YAML 显隐**：一键控制，省出宝贵的便签空间

更妙的是，工具栏支持**智能自动隐藏**——鼠标移出便签时工具栏平滑淡出，移回来时自然浮现。不写字的时候，你看到的就是一张干干净净的便签纸。

### 🗂️ 便笺管理器 (Notes Hub)

便签多了怎么找？点一下左侧的网格图标，弹出瀑布流卡片面板：

- 每张卡片展示便签的皮肤底色、修改时间和正文摘要
- 顶部搜索栏即时过滤，毫秒级响应
- 点击卡片，对应的便签小窗立刻在桌面上复活
- 角落有垃圾桶图标，一键清理废弃便签

### 🖥️ 多屏越界保护

拔掉外接显示器后，有些便签窗口会飘到"不存在的屏幕"上。这个插件会自动检测，把越界的便签拉回当前可视区域。小细节，但用过多屏的人都懂这有多重要。

## 为什么是"在 Obsidian 里"用便签？

你可能会问：市面上有很多独立便签 App，Stickies、Notezilla、甚至微软自带的 Sticky Notes，为什么非要在 Obsidian 里用？

答案只有一个词：**归一。**

| 维度 | 独立便签 App | Obsidian 桌面便笺 |
|:---|:---|:---|
| 数据格式 | 私有格式或富文本 | **标准 Markdown `.md` 文件** |
| 全库搜索 | ❌ 搜不到 | ✅ Obsidian 全局搜索直接命中 |
| 双向链接 | ❌ | ✅ `[[笔记名]]` 直接关联 |
| 标签体系 | ❌ | ✅ `#标签` 无缝整合 |
| 同步方案 | 需要单独配置 | ✅ 和你的库走同一个同步通道 |
| 插件生态 | 无 | ✅ Dataview、Templater 等均可作用于便签文件 |
| 数据归属 | 云端或 App 私有目录 | ✅ **100% 本地**，就在你的 Vault 里 |

**你在便签上随手写的三个字，也许就是未来某篇文章的种子。** 如果它从一开始就生长在你的知识库里，那这颗种子永远不会丢。

## 三分钟上手

**安装：**

1. 下载 `main.js`、`styles.css`、`manifest.json` 三个文件
2. 在你的 Vault 下找到 `.obsidian/plugins/`，新建文件夹 `desktop-sticky-notes`
3. 把三个文件丢进去
4. **设置 → 第三方插件 → 刷新 → 启用 Desktop Sticky Notes**

**使用：**

- 点左侧的 📝 便签纸图标 → 新建一张便签
- 点左侧的 ⊞ 网格图标 → 打开便签管理器
- 右键任意 `.md` 笔记 → **以桌面便笺打开**
- `Ctrl+P` → 输入"便笺"→ 三个命令任你选

**设置项：**

- 便签保存目录（默认 `Sticky Notes/`）
- 默认皮肤配色
- 默认窗口宽高
- 是否默认置顶
- 工具栏自动隐藏开关

全部中英文自动切换，跟随你的 Obsidian 语言设置。

## 写在最后

便签的本质是**降低记录的摩擦**。系统便签做到了一半——它让你快速写下来，但写下来的东西和你的知识体系毫无关系。

Desktop Sticky Notes 做的是另一半：**让每一条碎片想法，从诞生的那一秒起，就是你知识库的一部分。**

不用改变你使用便签的习惯，只需要换一个地方贴。
