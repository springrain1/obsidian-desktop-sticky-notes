# 桌面便笺 (Desktop Sticky Notes) 功能使用说明书

欢迎使用 **Desktop Sticky Notes（桌面便笺）**！本插件旨在将独立无边框拟物桌面便笺手感，与 Obsidian 原生强大的知识库生态深度融合。

---

## 一、 快速入门

### 1. 新建便笺
你可以通过以下三种便捷方式随时新建一张便笺：
1. **左侧功能区 (Ribbon)**：点击 Obsidian 最左侧工具栏上的「便签纸图标」；
2. **命令面板**：按快捷键 `Ctrl+P`（Mac 为 `Cmd+P`），输入并运行 `新建桌面便笺`；
3. **便笺窗口内连续新建**：在已打开的任意桌面便笺工具栏上，直接点击最左侧的 `+` 号按钮。

> 每次新建便笺时，系统会在你的 Vault 库指定目录（默认 `Sticky Notes/`）自动创建一个带有时间戳命名的 Markdown 文件，并以独立的桌面便笺小窗弹出。

### 2. 将库内已有笔记作为桌面便笺打开
- 在 Obsidian 文件列表树中，**右键点击**任意 Markdown 笔记；
- 在上下文菜单中点击 **「以桌面便笺打开 (Open as desktop sticky note)」**；
- 该笔记即刻脱离主窗口，以独立的桌面便笺小窗呈现。

### 3. 打开桌面便笺管理器 (Notes Hub)
- 点击左侧功能区的「网格图标」；
- 或按 `Ctrl+P` 运行 **「打开桌面便笺管理器」**；
- 弹出的管理器面板将以瀑布流卡片展示所有便笺，支持即时搜索与双击唤醒。

## 二、 悬浮工具栏功能全解

每张桌面便笺的顶部都集成了一条精致的便笺工具栏，从左至右依次为：

| 图标 | 功能名称 | 交互与核心亮点 |
| :---: | :--- | :--- |
| `+` | **新建便笺** | 快速创建并弹出新的桌面便笺卡片。 |
| 📌 | **桌面置顶 (Pin)** | 点击切换便笺置顶状态。置顶时图标**高亮变红**，便笺将常驻在 Windows 桌面所有应用（如浏览器、Word、IDE 等）最上层；再次点击取消置顶。 |
| 🎨 | **皮肤换色** | 点击弹出气泡调色盘，内置 7 种经典便笺底色（含暗夜黑），点击即刻换肤，并自动关闭面板。 |
| ☑️ | **待办清单** | 在光标行插入 `- [ ] `，光标自动定位在待办输入位；**支持多选多行批量打勾或批量转为待办**。 |
| 📜 | **项目符号列表** | 插入无序列表 `- `；**支持多选多行批量转换为无序列表**。 |
| 🔢 | **编号列表** | 插入有序列表 `1. `；**选中多行时自动按顺序递增编号**（`1. `、`2. `、`3. ` ...）。 |
| <s>S</s> | **删除线** | 选中文本一键添加或移除 `~~` 删除线包裹；未选中文本时光标自动落在中间。 |
| 🖼️ | **插入图片** | **默认直接打开系统资源管理器**，选择图片后自动存入 Vault 附件目录并插入标准引用；亦可直接用 `Ctrl+V` 粘贴剪贴板截图。 |
| **H** | **显示/隐藏标题** | 默认隐藏便笺顶部的内联标题（避免占用宝贵空间），点击切换显示，高亮即为开启。 |
| `</>` | **显示/隐藏 YAML** | 默认隐藏笔记开头的属性面板/元数据区域，点击切换显示，高亮即为开启。 |
| 🗑️ | **移入废纸篓** | 一键将当前便笺移入系统/Obsidian 回收站，安全删除文件并关闭窗口。 |
| ✖️ | **关闭便笺** | 安全关闭桌面悬浮小窗（数据已实时自动保存，随时可在便笺管理器找回）。 |

## 三、 高效编辑与交互细节

### 1. 原生 Live Preview 所见即所得
便笺内部直接由 Obsidian 原生 CodeMirror 6 驱动：
- 敲入 `- [ ] ` 时直接实时呈现为**可直接用鼠标打勾/取消**的漂亮复选框；
- 敲入 `# 一级标题`、`**加粗**`、`==高亮==`，即打即显，无缝呈现富文本质感；
- 支持 Obsidian 双向链链接 `[[其他笔记]]`，便笺亦是你的第二大脑入口。

### 2. 工具栏居中与智能自动隐藏
- **绝对居中**：无论便笺拉宽还是收缩，中间的核心富文本工具条始终保持在窗口正中央，视觉严谨对称；
- **鼠标离开自动隐藏**：光标离开便笺窗口时，工具栏按钮自动平滑淡出，展现出纯粹清爽的拟物便笺纸；鼠标一移回便笺窗口上方，工具栏即刻自然浮现（支持在设置中开启或关闭此功能）。

### 3. 便笺列表管理器 (Sticky Notes Hub)
点击左侧功能区的网格图标（或按 `Ctrl+P` 运行「打开桌面便笺管理器」），可唤出全量便笺管理器面板：
- **即时搜索**：键入关键词，卡片流毫秒级过滤匹配；
- **色彩预览**：直观展示便笺皮肤底色、修改时间与正文摘要；
- **重新激活**：点击卡片，即可在桌面上重新唤醒已关闭的独立便笺小窗；
- **快速清理**：卡片右下角悬停提供垃圾桶图标，一键将废弃便笺移入回收站。

### 4. 7 款经典拟物便笺纸配色 (含暗夜碳黑)
点击调色盘图标，可在以下 7 种配色中秒切：
- 🟡 **经典黄** (`#FFF8B8`)：最经典的纸质便签感，柔和暖目；
- 🟢 **薄荷绿** (`#D8F3DC`)：清新自然，适合日程与任务规划；
- 🌸 **樱花粉** (`#FFE3E3`)：温和醒目，适合灵感与重要备忘；
- 🔷 **晴空蓝** (`#E0F2FE`)：沉稳干练，适合工作流程与开发手记；
- 🟣 **香芋紫** (`#F3E8FF`)：优雅雅致，适合读书札记与思考片段；
- ⚪ **简约白** (`#FFFFFF`)：纯净黑白，极简专注；
- ⚫ **暗夜碳黑 (Charcoal)** (`#202020`)：专为深色模式与夜间护眼设计的高级黑。

### 5. 国际化 (i18n) 语言支持
插件全面支持简体中文与 English 原生国际化：
- 在中文语言环境下，命令与菜单显示为纯正简体中文（如「新建桌面便笺」、「打开桌面便笺管理器」）；
- 在英文语言环境下，自动切换为规范英文（如 "New desktop sticky note", "Open desktop sticky notes hub"）；
- 工具栏提示（Tooltips）、设置选项、皮肤名称与系统通知均已完成完整适配。

## 四、 插件配置说明

在 Obsidian「设置」➔「第三方插件」➔「Desktop Sticky Notes」中，可根据使用习惯调整以下参数：

1. **便笺保存目录**（默认：`Sticky Notes`）：新建便笺时的默认 Vault 文件夹。
2. **新建便笺默认配色**：初始便笺纸皮肤（默认经典黄）。
3. **默认宽度 / 默认高度**：新建便笺小窗口弹出时的初始几何尺寸（默认 320px × 380px）。
4. **默认窗口置顶**：新建便笺时是否默认保持在桌面最顶层。
5. **鼠标离开自动隐藏工具栏**：是否在鼠标离开便笺时平滑淡出顶栏。

## 五、 常见问题解答 (FAQ)

**Q1：便笺里的数据保存在哪里？**  
**A**：完全保存在你本地 Vault 的指定文件夹（如 `Sticky Notes/`）内，全部是纯粹的 `.md` Markdown 文本文件，不依赖任何第三方云端。

**Q2：从资源管理器选择的图片保存在哪里？**  
**A**：遵循 Obsidian 官方全局设置（「设置」➔「文件与链接」➔「附件默认存放路径」），图片自动以原画保存在你的附件目录中，并生成标准的 Obsidian 嵌入链接。

**Q3：为什么需要隐藏顶部的标签页和标题？**  
**A**：Obsidian 在弹出独立窗口时，默认会带有标签栏和标题区域。作为桌面便笺，空间寸土寸金，且多余的标签栏会破坏便笺纸的轻量拟物体验。本插件默认隐藏了这些区域，并通过工具栏按钮提供随需呼出的能力。
