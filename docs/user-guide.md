# 印象笔记桌面便签 (Evernote Sticky Note) 功能使用说明书

欢迎使用 **Evernote Sticky Note**！本插件旨在将原版 Windows 印象笔记（`Evernote.exe`）经典的独立无边框拟物桌面便签手感，与 Obsidian 原生强大的知识库生态深度融合。

---

## 一、 快速入门

### 1. 新建便签
你可以通过以下三种便捷方式随时新建一张便签：
1. **左侧功能区 (Ribbon)**：点击 Obsidian 最左侧工具栏上的「便签纸图标」；
2. **命令面板**：按快捷键 `Ctrl+P`（Mac 为 `Cmd+P`），输入并运行 `新建桌面便签 (new sticky note)`；
3. **便签窗口内连续新建**：在已打开的任意桌面便签工具栏上，直接点击最左侧的 `+` 号按钮。

> 每次新建便签时，系统会在你的 Vault 库指定目录（默认 `Sticky Notes/`）自动创建一个带有时间戳命名的 Markdown 文件，并以独立的桌面便签小窗弹出。

### 2. 将库内已有笔记作为桌面便签打开
- 在 Obsidian 文件列表树中，**右键点击**任意 Markdown 笔记；
- 在上下文菜单中点击 **「以桌面便签打开 (open as sticky note)」**；
- 该笔记即刻脱离主窗口，以独立的桌面便签小窗呈现。

## 二、 悬浮工具栏功能全解

每张桌面便签的顶部都集成了一条原汁原味的便签工具栏，从左至右依次为：

| 图标 | 功能名称 | 交互与核心亮点 |
| :---: | :--- | :--- |
| `+` | **新建便签** | 快速创建并弹出新的桌面便签卡片。 |
| 📌 | **桌面置顶 (Pin)** | 点击切换便签置顶状态。置顶时图标**高亮变红**，便签将常驻在 Windows 桌面所有应用（如浏览器、Word、IDE 等）最上层；再次点击取消置顶。 |
| 🎨 | **皮肤换色** | 点击弹出气泡调色盘，内置 6 种原版经典便签底色，点击即刻换肤，并自动关闭面板。 |
| ☑️ | **待办清单** | 在光标行插入 `- [ ] `，光标自动定位在待办输入位；**支持多选多行批量打勾或批量转为待办**。 |
| 📜 | **项目符号列表** | 插入无序列表 `- `；**支持多选多行批量转换为无序列表**。 |
| 🔢 | **编号列表** | 插入有序列表 `1. `；**选中多行时自动按顺序递增编号**（`1. `、`2. `、`3. ` ...）。 |
| <s>S</s> | **删除线** | 选中文本一键添加或移除 `~~` 删除线包裹；未选中文本时光标自动落在中间。 |
| 🖼️ | **插入图片** | **默认直接打开 Windows 资源管理器**，选择图片后自动存入 Vault 附件目录并插入标准引用；亦可直接用 `Ctrl+V` 粘贴剪贴板截图。 |
| **H** | **显示/隐藏标题** | 默认隐藏便签顶部的内联标题（避免占用宝贵空间），点击切换显示，高亮即为开启。 |
| `</>` | **显示/隐藏 YAML** | 默认隐藏笔记开头的属性面板/元数据区域，点击切换显示，高亮即为开启。 |
| ✖️ | **关闭便签** | 点击安全关闭当前便签窗口。内容会自动完成存盘，毫无丢数据风险。 |

## 三、 高效编辑与交互细节

### 1. 原生 Live Preview 所见即所得
便签内部直接由 Obsidian 原生 CodeMirror 6 驱动：
- 敲入 `- [ ] ` 时直接实时呈现为**可直接用鼠标打勾/取消**的漂亮复选框；
- 敲入 `# 一级标题`、`**加粗**`、`==高亮==`，即打即显，无缝呈现富文本质感；
- 支持 Obsidian 双向链链接 `[[其他笔记]]`，便签亦是你的第二大脑入口。

### 2. 工具栏居中与智能自动隐藏
- **绝对居中**：无论便签拉宽还是收缩，中间的核心富文本工具条始终保持在窗口正中央，视觉严谨对称；
- **鼠标离开自动隐藏**：光标离开便签窗口时，工具栏按钮自动平滑淡出，展现出纯粹清爽的拟物便签纸；鼠标一移回便签窗口上方，工具栏即刻自然浮现（支持在设置中开启或关闭此功能）。

### 3. 6 款经典拟物便签纸配色
点击调色盘图标，可在以下预设配色中秒切：
- 🟡 **经典黄** (`#FFF8B8`)：最经典的纸质便签感，柔和暖目；
- 🟢 **薄荷绿** (`#D8F3DC`)：清新自然，适合日程与任务规划；
- 🌸 **樱花粉** (`#FFE3E3`)：温和醒目，适合灵感与重要备忘；
- 🔷 **晴空蓝** (`#E0F2FE`)：沉稳干练，适合工作流程与开发手记；
- 🟣 **香芋紫** (`#F3E8FF`)：优雅雅致，适合读书札记与思考片段；
- ⚪ **简约白** (`#FFFFFF`)：纯净黑白，极简专注。

### 3. 多行选中批量转换
针对写好的大段文本，只需鼠标划选多行：
- 点击 **待办清单** ➔ 每一行整齐划一转换为待办任务框；
- 点击 **有序列表** ➔ 系统自动为选中的每一行编排递增序号（1, 2, 3...）；
- 再次点击同个按钮 ➔ 批量取消列表标记，恢复普通文本。

### 4. 窗口记忆与持久化
- **尺寸与位置记忆**：便签窗口在桌面上移动、拖拽拉伸尺寸后，系统会在后台自动将坐标与宽高记录到笔记前置 YAML 的 `bounds` 字段中。下次重新打开时保持原有桌面位置。
- **配置同步**：配色（`color`）和置顶状态（`pinned`）自动写入 Frontmatter，多端无损保留。

### 5. 国际化 (i18n) 语言支持
插件全面支持简体中文与 English 原生国际化：
- 在中文语言环境下，命令与菜单显示为纯正简体中文（如「新建桌面便签」、「以桌面便签打开」）；
- 在英文语言环境下，自动切换为规范英文（如 "New sticky note", "Open as sticky note"）；
- 工具栏提示（Tooltips）、设置选项、皮肤名称与系统通知均已完成完整适配。

## 四、 插件配置说明

在 Obsidian「设置」➔「第三方插件」➔「Evernote Sticky Note」中，可根据使用习惯调整以下参数：

1. **便签保存目录**（默认：`Sticky Notes`）：新建便签时的默认 Vault 文件夹。
2. **新建便签默认配色**：初始便签纸皮肤（默认经典黄）。
3. **默认宽度 / 默认高度**：新建便签小窗口弹出时的初始几何尺寸（默认 320px × 380px）。
4. **默认窗口置顶**：新建便签时是否默认保持在桌面最顶层。
5. **自动存盘延迟**：输入停止后向文件落盘的防抖时间（默认 400ms）。

## 五、 常见问题解答 (FAQ)

**Q1：便签里的数据保存在哪里？**  
**A**：完全保存在你本地 Vault 的指定文件夹（如 `Sticky Notes/`）内，全部是纯粹的 `.md` Markdown 文本文件，不依赖任何第三方云端。

**Q2：从资源管理器选择的图片保存在哪里？**  
**A**：遵循 Obsidian 官方全局设置（「设置」➔「文件与链接」➔「附件默认存放路径」），图片自动以原画保存在你的附件目录中，并生成标准的 Obsidian 嵌入链接。

**Q3：为什么需要隐藏顶部的标签页和标题？**  
**A**：Obsidian 在弹出独立窗口时，默认会带有标签栏和标题区域。作为桌面便签，空间寸土寸金，且多余的标签栏会破坏“便签纸”的轻量拟物体验。本插件默认隐藏了这些区域，并通过工具栏按钮提供随需呼出的能力。
