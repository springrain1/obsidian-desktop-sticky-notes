# 桌面便笺 (Desktop Sticky Notes) 知识管理与 Obsidian Markdown 特性测试用例集

本目录提供了一套深度结合 **Obsidian Markdown 专属特性** 与 **个人知识管理 (PKM) 真实场景** 的实战测试用例。你可以直接将本文件夹中的文件拷贝至你的 Vault 库中（如放入 `Sticky Notes/` 文件夹），在桌面悬浮独立小窗中亲身体验“**传统便签的轻快无感 + Obsidian 知识网络的深邃联动**”。

---

| **Wiki 双向链接** | `[[知识网络]]`、`[[笔记#标题]]`、`[[书籍\|别名]]` | 悬浮小窗内直接点击跳转、悬停预览 Page Preview | `01`, `02`, `04` |

## 🧭 知识管理实战场景全览

```
  [ 闪念碎片 / 外部网页 / 会议网课 ]
                  │
                  ▼
   ╭──────────────────────────────╮
   │   桌面便笺 (Desktop Sticky)  │ ◄── 零摩擦输入、桌面置顶、真富文本
   ╰──────────────┬───────────────╯
                  │ 自动保存为标准 .md
                  ▼
   ╭──────────────────────────────╮
   │  便笺管理器 (Notes Hub 检索) │ ◄── 瀑布流检索、色彩分类、快速唤醒
   ╰──────────────┬───────────────╯
                  │ 提炼升华
                  ▼
   ╭──────────────────────────────╮
   │  Obsidian 永久知识网络 (Vault)│ ◄── 双链拓扑、图谱视图、Dataview 索引
   ╰──────────────────────────────╯
```

### 1. `01-今日待办与闪念收集.md`（经典黄 🟡）
- **核心场景**：GTD 每日专注三件事、随手灵感捕捉箱；
- **测试特性**：原生可点击 Checkbox、`==荧光笔高亮==`、`> [!tip]` 标注框、层级标签 `#gtd/today`、行内 Dataview 字段。

### 2. `02-多源阅读与对照参考.md`（薄荷绿 🟢）
- **核心场景**：浏览器查论文、跨窗口写作对照参考台；
- **测试特性**：带有别名与小节的双向链接 `[[...|...]]`、多行选中批量递增编号、删除线 `~~`、轻量打卡对比表。

### 3. `03-暗夜极客与会议手记.md`（暗夜碳黑 ⚫）
- **核心场景**：全屏看视频/开会时置顶悬停、夜间工作极客手记；
- **测试特性**：**暗夜碳黑皮肤**、代码语法高亮、从资源管理器选图插入、`Ctrl+V` 剪贴板截图直贴、块引用 `^meeting-action`。

### 4. `04-卡片盒与知识沉淀工作流.md`（樱花粉 🌸）
- **核心场景**：卢曼卡片盒（Zettelkasten）从闪念到永久笔记流转；
- **测试特性**：工具栏一键展开/隐藏 YAML 元数据与内联大标题、主库 Dataview 聚合演示、反向链接追踪。

### 5. `05-科研公式与心流推导.md`（晴空蓝 🔷）
- **核心场景**：学生、学者、工程师的演算草稿纸；
- **测试特性**：行内与多行 LaTeX 数学公式实时渲染、`> [!math]` 与 `> [!example]` 标注框、常数对照表。

## 🚀 极速体验指南

1. 将本文件夹（`docs/test-cases/`）复制到你的 Vault 库中的便笺文件夹（默认 `Sticky Notes/`）；
2. 点击 Obsidian 左侧 Ribbon 的 **网格图标** 打开 **便笺管理器 (Sticky Notes Hub)**；
3. 瀑布流中将直接呈现 5 种不同色彩与排版的精美卡片；
4. 点击任意一张卡片，立刻在桌面上唤醒独立悬浮小窗，体验原生 Live Preview 实时预览！
