### 🌸 卢曼卡片盒与知识沉淀 (Zettelkasten)

> [!abstract] 灵感从碎片到大厦
> “便笺不只是临时的备忘便签，它应当是知识晶体生长的种子。”

#### 知识流转四步法：
1. **闪念捕获 (Capture)**：在便笺中快速记下灵感碎片（无需格式包袱）；
2. **随需显隐 (Clean UI)**：
   - 点击工具栏的 **`H` 按钮**，随时呼出或收起笔记大标题；
   - 点击工具栏的 **`</>` 按钮**，随时展开或隐藏上方的 YAML 属性与标签面板；
3. **双链连接 (Connect)**：便笺内可直接键入 `[[知识管理方法论]]`，让碎片无缝嵌入全局知识图谱；
4. **主库检索与聚合 (Synthesize)**：
   在主库任意汇总页中，通过 Dataview 插件一键汇聚所有活动便笺：

```dataview
TABLE file.mtime AS "更新时间", color AS "便笺底色"
FROM #fleeting-note
SORT file.mtime DESC
```
