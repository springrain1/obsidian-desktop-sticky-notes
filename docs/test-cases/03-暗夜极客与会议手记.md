### 🌙 暗夜极客手记 (Charcoal Dark Mode) #dev #meeting

专为夜间深度工作、网课学习或视频会议打造的深色便笺纸：

```typescript
// 灵感代码片段随时贴在桌面一角
interface StickyInspiration {
    source: "Zoom Meeting" | "Paper" | "Bilibili";
    actionable: boolean;
    timestamp: number;
}
```

> [!note] 架构决策与行动项
> 采用直接挂载原生 `MarkdownView` (Live Preview) 方案，性能最佳，内存零开销。 ^meeting-action-01

- 🎧 **会议全屏置顶**：开全屏网课或 Zoom 会议时，点击置顶图钉让便笺悬浮在画面边缘；
- 🖼️ **选图插入与截图直贴**：
  - 点击工具栏图片图标，直接唤起 Windows 资源管理器选择图片文件；
  - 或者截屏后在此按下 `Ctrl+V`，图片自动存入 Vault 附件并**即时渲染**！
- 🌿 **纯黑护眼**：夜晚不刺眼，文本选区、光标与代码块高亮在碳黑底色下自动适配。
