**Desktop Stickies** 是一款专为 Obsidian 打造的现代化拟物风独立桌面便笺插件。融合**经典纸质桌面便笺交互**与 **Obsidian 原生 Live Preview 实时预览引擎**，既保留了桌面便笺即开即写、常驻桌面的轻量手感，又让所有灵感数据无缝沉淀在你的本地 Markdown 知识库中。

---

## 🌟 核心特性全景 (Features)

### 🪟 1. 独立窗口与三态物理空间系统 (Window & Space Management)
- **原生独立悬浮小窗**：摆脱主库窗格分割限制，每一个便签都是一个独立的操作系统窗口，自由拖拽缩放；
- **⚓ 真·桌面小组件模式 (Desktop Widget)**：
  - 挂载系统桌面宿主（Progman），**按 `Win+D`（显示桌面）时所有常规软件最小化，便签稳稳留在壁纸上常驻**；
  - 保持完整打字与打勾交互；鼠标移回其他应用时触发失焦（blur），50ms 自动平滑重置为底层（`HWND_BOTTOM`），绝不遮挡后续工作；
- **📌 窗口置顶模式 (Always on Top / Pin)**：一键置顶在一切软件之上，适合边查资料边对照速记、开会记要等高频参考场景；
- **单按钮三态物理空间流转**：通过顶部工具栏图钉按钮在 `普通浮动 (Float)` ➔ `窗口置顶 (Pin)` ➔ `桌面小组件 (Widget)` 之间自由切换（亦可在设置中开启经典二态）；
- **📐 自定义极窄边框与间距可设**：
  - 设置面板提供「正文上下间距（0~30px）」与「正文左右间距（0~30px）」滑块；
  - 调为 `0` 时，通过 API 级拔除行宽限制并清空滚动槽位，**文字真正从最左侧第 0 像素贴边延展至最右侧边缘，实现极限窄边框**；
- **🤫 关闭便签绝对零打扰**：随手点击右上角关闭（✕）或删除时，直接关闭独立宿主小窗，**绝不再强行弹出激活庞大的 Obsidian 主窗口**；
- **🧹 任务栏防拥挤 (Skip Taskbar)**：便签小窗自动从 Windows 任务栏隐藏，任务栏永远只保留 1 个主程序图标，保持桌面清爽；
- **🔄 收回至主库**：提供「恢复为主窗口」按钮，一键将独立的桌面便签无缝收回收纳至 Obsidian 主库的普通 Tab 标签页；
- **💾 物理坐标与尺寸 1:1 精准记忆**：
  - 二次定位强力注入内容尺寸，用户自定义的高度（如 250px）在下一次打开时 100% 绝对 1:1 复原；
  - 尺寸采集严格基于内容区，彻底消除开合循环外边框膨胀；
  - 监听原生 Electron `move` 事件，真正做到拖拽松手 500ms 静默存盘；外接副屏拔除后自动拉回主屏可视视野。

### ✍️ 2. 原生 Live Preview 与富文本快捷工具栏 (Editor & Toolbar)
- **所见即所得实时预览 (Live Preview)**：直接输入 Markdown 语法，标题、列表、复选框、高亮即打即显，原生支持光标聚焦；
- **🛠️ 全套快捷富文本工具栏**：
  - **待办清单 (Checklist)**：插入/切换待办复选框，支持多行选中文本一键批量打勾或取消；
  - **智能列表转换**：无序列表一键转换；有序列表智能自动递增编号（1. 2. 3...）；
  - **删除线快速包裹**：选中文本一键添加 `~~删除线~~`；
  - **一键插入本地图片**：点击按钮直接拉起系统文件管理器选图，自动存入 Vault 附件文件夹并生成标准引用语法；
  - **标题与 YAML 一键显隐**：默认隐藏顶栏多余标题和 Frontmatter 属性面板，提供独立按钮随需展开；
- **🪟 中间格式工具栏隐藏开关**：设置面板提供开关，一键隐藏中间格式化按钮；隐藏后顶部整条大面积区域直接作为拖拽抓手，随手一抓即可移动便签。

### 🎨 3. 拟物纸质皮肤与全语法暗夜极客模式 (Skins & Themes)
- **7 款经典拟物纸质皮肤**：经典黄、薄荷绿、樱花粉、晴空蓝、香芋紫、简约白，以及专为深色模式打造的暗夜碳黑 (Charcoal)；
- **🌑 暗夜碳黑全语法高对比度兼容**：
  - **光标 2px 耀眼亮白**：光标与输入点全链路绑定明亮文字色，告别深黑背景下光标隐形消失；
  - **动态深色渲染管线**：切换暗色便签时自动切换宿主窗口的主题上下文（`theme-dark`）；
  - **全套排版语法立体适配**：表格（表头与单元格）、Callout 标注块（含中性灰 quote 类型）、未创建内部双链（`is-unresolved`）、引用块、LaTeX 数学公式、代码块全部赋予明亮高对比度呈现，告别“黑底写黑字”；
- **🫧 智能自动隐藏工具栏**：鼠标移出便笺时工具栏平滑淡出，移入时优雅浮现，提供如同真实实体便签纸般的极简沉浸感。

### 🗂️ 4. 桌面便笺管理器与数据安全 (Hub & Data Safety)
- **桌面便笺管理器 (Sticky Notes Hub)**：主库一键唤出管理器模态框，瀑布流卡片检索所有便笺，支持关键字即时过滤、查看、重新唤醒或移入废纸篓；
- **💾 100% 本地纯纯 Markdown 存储**：不依赖任何第三方云服务，所有便签均是标准的本地 `.md` 文件，位置、尺寸、皮肤、窗口状态自动存入 YAML Frontmatter，天然适配全平台备份与同步；
- **🌐 原生中英文国际化 (i18n)**：自动识别 Obsidian 系统语言，命令、设置、工具栏与提示无缝切换中文/英文。

## 🚀 快速上手 (Quick Start)

### 1. 手动安装
1. 在 [GitHub Releases](https://github.com/springrain1/obsidian-desktop-sticky-notes/releases) 页面下载最新构建产物 `main.js`、`styles.css`、`manifest.json`；
2. 在您的 Obsidian 库目录中，进入 `.obsidian/plugins/`，新建文件夹 `desktop-stickies`；
3. 将上述三个文件拷贝到该文件夹中；
4. 在 Obsidian 的「设置」➔「第三方插件」中刷新并启用 **Desktop Stickies**。

### 2. 常用操作
- **新建便笺**：点击左侧功能栏（Ribbon）的便签纸图标，或按 `Ctrl+P` 输入 `新建桌面便笺`；
- **打开管理器**：点击左侧功能栏的网格图标，或按 `Ctrl+P` 输入 `打开桌面便笺管理器`；
- **以便笺打开现有笔记**：右键库内任意 `.md` 笔记，选择「以桌面便笺打开」；
- **切换形态**：点击工具栏左侧的 📌 按钮，在普通浮动、窗口置顶、桌面小组件之间自由循环；
- **关闭便笺**：点击便笺右上角的 `×`，内容已实时落盘，窗口自然退出且不打扰前台工作；
- **删除便笺**：点击便笺右上角的 `🗑️` 垃圾桶图标，将笔记移入废纸篓。
